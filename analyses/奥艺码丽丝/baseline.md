## 二、待证伪的假设清单

### H1　能动率

- **当前主张**：能动率 92.16%，是本卡组的上界。
- **模拟怎么测**：固定种子，随机洗 20,000 手，用贪心策略跑完先攻回合，统计「终场至少有 1 只码丽丝连接怪兽」的比例。
- **判定**：落在 85%~95% → 主张成立；低于 80% → 推导严重高估（大概率是三月兔那条）；高于 97% → 策略过强或有 bug。

### H2　梦游地下界是单卡动点

- **当前主张**：是，而且不吃通召。
- **模拟怎么测**：只给「1 张梦游地下界 + 4 张无关卡（如 4 张手坑）」，跑 1,000 次，看能否做出连接怪兽。
- **判定**：成功率 > 90% → 成立；< 50% → 我判错了。

### H3　三月兔不是单卡动点

- **当前主张**：不是，它必须除外手里另一张码丽丝才能自跳。
- **模拟怎么测**：只给「1 张三月兔 + 4 张非码丽丝卡」，跑 1,000 次。
- **判定**：成功率应 ≈ 0%。若明显 > 0，说明我漏了它的其他用法。

### H4　备份员是不是动点

- **当前主张**：分析里判 extender（要场上有电子界怪兽），推导判 starter。
- **模拟怎么测**：只给「1 张备份员 + 4 张无关卡」，跑 1,000 次，看能否做出 1 只连接怪兽。
- **判定**：这是我和自动推导的分歧点，谁对谁错由它决定。

### H5　白兔线 9 步可复现

- **当前主张**：报告里那条 9 步做场线成立，终场是红心加密＋白棋捆绑。
- **模拟怎么测**：按步骤顺序逐条下指令，引擎不报非法动作，且终场与报告一致。
- **判定**：任何一步返回「非法动作」即该线作废，需要重写。

### H6　灰流丽影响 minor

- **当前主张**：核心启动走「从卡组除外」，灰流丽只能打到检索线。
- **模拟怎么测**：对手开局持有灰流丽，在最优时机使用；对比无手坑时的终场干扰点数。
- **判定**：平均干扰点下降 ≤ 1 → minor 成立；下降 ≥ 2 → 应改判 significant。

### H7　增殖的G 影响 critical

- **当前主张**：一回合 5 次以上特召，吃 G 几乎等于输。
- **模拟怎么测**：对手第 1 次特召时丢 G；策略按「能建立最低阻抗就停手」执行；对比终场。
- **判定**：最优停手点下终场干扰点 < 2 → critical 成立；若仍能做出 3 点以上 → 应降级。

### H8　天下独步之大义贼 highly_effective

- **当前主张**：后手能直接解放对方 2 只怪兽上级召唤，是最重要的一换多。
- **模拟怎么测**：先手方做出标准终场，后手方持有 1 张大义贼，看能拆掉几个干扰点。
- **判定**：拆掉 ≥ 2 点 → highly_effective 成立；只拆 0~1 点 → 改判 partially_effective。

## 三、接入后预期会变的东西

| 产物 | 现在 | 接入后 |
|---|---|---|
| `combos.json` | 自动推导的 7+3 条规则 | 由模拟出的「能/不能」直接生成 |
| `hand_matrix.json` | 数牌组合计数 | 每手的模拟结果 |
| `deck_analysis.json` 的 `combo_lines` | 按卡面写，`verified: false` | 引擎 move log，`verified: true` |
| 手坑敏感度 | 人工分级 | 每个手坑跑 N 次，给出干扰点下降的分布 |
| 六维评分 | 主观 | consistency / ceiling / resilience 可由模拟数据支撑 |

**不会变**：meta 判断、构筑好坏（需要对手模型）、六维里的「主观部分」仍是判断。

## 四、复现方式

```bash
# 机械步骤（离线可重跑，两次结果一致）
python skills/deck-parser/scripts/script_facts.py --ydk decks/奥艺码丽丝.ydk \
  --cache .cache/ygopro-scripts --cdb {cards.cdb} --offline -o {A}/script_facts.json
python skills/deck-parser/scripts/combo_scan.py {A}/deck_raw.json -o {A}/combo_candidates.json
python skills/deck-parser/scripts/hand_matrix.py {A}/deck_raw.json --derive \
  --facts {A}/script_facts.json --candidates {A}/combo_candidates.json \
  --cdb {cards.cdb} --write-rules {A}/combos.json -o {A}/hand_matrix.json

# 全量校验
python skills/ygo-deck-analyze/scripts/verify.py {A} --cdb {cards.cdb}
```

复现验证：连续两次跑出 `能动 92.16% / 死手 7.84%`，与 `deck_parsed.json` 记录一致。
