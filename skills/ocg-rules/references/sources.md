## 覆盖率

规则书正文合计 **2906 行**（12 个 `.rst`）。本清单提炼自其中约 **600 行**：

- 完整读过：`效果以外的文本`（58 行）、`游戏的进行`（275 行）
- 定点精读：`卡片的效果` 的 cost / 时点 / 连锁 / 无效 / 处理 等段落；`卡片` 的召唤 / 连接 / 衍生物 / 陷阱 / 怪兽效果 等段落
- **未覆盖**：伤害步骤细则、各卡种（仪式/融合/S/X/P）的召唤细节、区域规则、`c01/` 三篇、大会规则

未覆盖的部分目前判断为对「构筑与展开是否合法」影响很小；若之后发现缺口，按条款名回原文补。

## 引用原则

- 只引用**条款名 + 行号**，不复制原文段落
- 清单正文是对规则的**转述与重组**，不是原文节选
- 规则书原文**不进仓库**：上游文档的著作权归原作者，本仓库仅以 Apache 2.0 分发自己的清单

## 已知边界

- 这是 **2020 版**规则。OCG 之后未再改动大师规则，但**卡片文本的写法在持续演化**（例如「这个卡名的效果」的措辞习惯）；新卡以卡面文本为准
- 规则书**不含单卡裁定**。像「某张卡在某个时点能不能发」属于 Q&A 范畴，需要另行查阅
- 未收录：伤害步骤细则、大会规则与罚则 —— 与卡组分析无关
