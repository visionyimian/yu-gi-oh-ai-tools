# ocg-rules

## 职责

- ✅ 提供**可执行的核对清单**：每条判据写成「文本特征 → 判定 → 必查项」
- ✅ 给出条款出处，便于回查原文
- ❌ 不做单卡裁定（那是 Q&A 的事，不是规则书的内容）
- ❌ 不替代 `deck-analyzer` 的对局判断，只校验「是否合法」

## 为什么是清单而不是规则书

完整规则书两百多页，大部分篇幅与卡组分析无关。真正会**推翻一条 combo 结论**的，集中在十几条判据上。所以这里只保留这些，并按「读卡时能直接对上」的方式重写。

规则书原文不随仓库分发（版权原因），只保留条款名与行号引用。

## 使用方式

### 1. 读卡阶段的快速分诊

遇到下面任一特征，必须去 `references/checks.md` 查对应条目：

| 文本里看到 | 查哪条 |
|---|---|
| `1回合只能使用1次` / `1回合1次` / `这个卡名的效果` | C1 |
| `时，~~才能发动` / `的场合，~~才能发动` | C2 |
| `这个效果在对方回合也能发动` | C3 |
| 多张卡同时被送去墓地 | C4 |
| `丢弃` / `送去墓地` / `解放` 作为发动条件 | C5 |
| `以~~为对象` / `选择` / `选` | C6 |
| `无效` | C7 |
| `通常召唤` / `召唤` / `盖放` | C8 |
| `解放` + 等级 | C9 |
| `连接召唤` / `作为连接素材` | C10 |
| `所连接区` / `连接标记` | C11 |
| `不能作为~~素材` / 特殊召唤条件 | C12 |
| `不能使用` / `不能发动` | C13 |
| 从额外卡组特殊召唤 / EX 区 | C14 |
| 衍生物（token） | C15 |
| `这张卡的发动从手卡也能用` | C16 |
| 效果处理时对象离场 / 来源不在场 | C17 |
| `那之后` / 多个处理同时进行 | C18 |
| 控制权转移 / 借怪 / 抢怪 | C19 |
| `盖放的回合` / 速攻魔法 | C20 |
| 手卡超过 6 张（结束阶段调整） | C21 |

**流程类问题**（什么时候能做什么、优先权归谁、阶段限制）不在清单里，看 [`references/flow.md`](references/flow.md)。

### 2. combo 复核（强制输出格式）

对每条展开路线，输出一张表。**没有这张表，视为没有做过规则复核**：

| 步骤 | 用到的效果 | OPT 类型 | 占用通召 | 自锁 | 时点风险 | 结论 |
|---|---|---|---|---|---|---|
| 1 | 白兔① | 卡名限定 | 是 | 无 | 无 | ✅ |
| 2 | 白兔③ | 卡名限定 | 否 | 连接限定 | 「場合」→ 不会错过 | ✅ |
| 3 | 陷阱卡发动 | 卡限定 | 否 | 无 | — | ⚠️ 例外 |

字段含义：

- **OPT 类型**：`卡名限定` / `卡限定` / `无`（见 C1）
- **占用通召**：这一步是否消耗了本回合的通常召唤权（见 C8）
- **自锁**：「这个回合自己不是 X 不能特殊召唤」这类限制，写 `无` 或具体限制
- **时点风险**：该触发是「時」还是「場合」，会不会因为前置处理而错过（见 C2）
- **结论**：`✅ 成立` / `⚠️ 有条件成立（写明条件）` / `❌ 不成立（写明原因）`

### 3. 结论回填

- `deck-parser`：`once_per_turn_type` 字段直接取 C1 的判定结果
- `deck-analyzer`：写终场与 Chokepoint 前，先用本清单确认那条线成立
- `ygo-deck-analyze`：Step 4.5 的动点校验引用本清单

### 4. 判例：限制的作用域

清单回答「这个效果怎么写」，[`references/rulings.md`](references/rulings.md) 回答「在场上怎么结算」。
做场分析里最容易错的是**限制跟谁走**：

| | 作用域 | 离场后 |
|---|---|---|
| R1「这个效果特殊召唤的怪兽不能发动效果」 | 绑卡片个体 | **解除**，回场可正常发动 |
| R2「这个回合自己不是 X 不能特殊召唤」 | 绑玩家 | **不解除**，整回合有效 |
| R3「这个卡名的效果 1 回合 1 次」 | 绑卡名 | 不重置 |

这三条直接决定「先拉一只被限制的怪当素材、再让它回场」这条增值链成不成立。

## 注意

- 规则书是 **2020 版**。OCG 自那之后没有改过大师规则，但**卡片文本的写法在演化**（例如「这个卡名的效果」的措辞变化），遇到新卡以卡面文本为准。
- 本清单只回答「合不合法」，不回答「强不强」。
